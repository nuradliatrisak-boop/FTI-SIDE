# FTI SIDE — hasil editing, revisi subtitle V2

File hasil:
- FTI-SIDE-PART-1.mp4 — 19:38,3
- FTI-SIDE-PART-2.mp4 — 18:31,7

Spesifikasi hasil: Full HD 1920×1080, 30 fps, MP4 H.264, yuv420p BT.709, audio AAC stereo 48 kHz 256 kb/s, subtitle tertanam. Kedua file telah lolos decode penuh audio/video, pemeriksaan format, durasi dan jumlah frame. Bukti pada QC-REPORT.json; kecocokan waveform enam titik pada AUDIO-ALIGNMENT-QC.json.

FTI-SIDE-OPENING-PREVIEW.mp4 adalah preview opening dengan footage asli dan musik. Preview kedua episode berisi opening, kartu episode, 90 detik awal percakapan episode tersebut dan penutup — bukan keseluruhan episode.

TRANSKRIP-LENGKAP.txt menggunakan timestamp sumber utuh. TRANSKRIP-SUMBER.srt dan dua SRT episode disertakan untuk revisi. EDIT-TIMESTAMPS.csv memetakan sumber ke timeline akhir. CATATAN-EPISODE.md menjelaskan pembagian dan keputusan editing.

Project Remotion berada di ../studio, source code di ../studio/src; skrip reproduksi dan ekspor di ../scripts. Footage asli berada di ../studio/public/sources, audio stereo olahan dan musik original di ../studio/public/audio. Jangan mengunduh ulang sumber yang sudah terverifikasi.

Subtitle berasal dari Whisper multilingual, dengan pemeriksaan ulang bagian tertentu, ejaan nama yang dikonfirmasi pengguna, dan koreksi terdokumentasi di ../docs/transcript-corrections.json. Bagian yang tetap ambigu diberi penanda [ucapan kurang jelas]. Peninjauan manusia menyeluruh atas setiap kata audio belum dilakukan; jangan menganggap akurasi bahasa sempurna dari keberhasilan decode teknis.

Identitas utama FTI SIDE. Kabinet ARKA disertakan melalui tipografi pada closing; logo resmi tidak digambar ulang. Musik instrumental dibuat khusus proyek tanpa sampel pihak ketiga.

Revisi V2: 27 potongan diperiksa ulang, 59 koreksi/penanda dan 118 perbaikan format. Tiga titik belum jelas tercantum di POTONGAN-PERLU-DICEK.csv. Versi awal dicadangkan di ../revisions/v1.
